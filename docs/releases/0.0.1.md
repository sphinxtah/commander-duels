# v0.0.1 — initial framework

## Included

- React/TypeScript shell with Play, Campaign, Learn, Decks, Cards, Collection, Profile and Settings.
- API-driven format descriptions, honest unavailable states, retry behavior, native format dialogs and device display preferences.
- FastAPI versioned contracts, liveness/readiness, request IDs and validated configuration.
- PostgreSQL schema foundation and reversible Alembic migration.
- Durable worker claim/recovery/fencing primitives with a bounded health-probe handler.
- Java 21 service boundary which explicitly rejects gameplay until engine integration.
- Generated browser API types, draft engine envelope and constrained draft content fixture.
- Docker development topology, CI workflow, tests and scope/architecture documentation.

## Not included

XMage adaptation, Google sign-in, catalog import, deck editing, actual matches, bots, campaign content, progression, installable PWA and offline gameplay remain open. This is neither a playable release nor completion of M0. No reference executable was available for audit.

## Verification

See `docs/verification.md` for commands executed and environment limitations. CI is supplied but has not run on a hosted repository. Version-tagged Docker artifacts need a successful daemon-backed build before release distribution.
