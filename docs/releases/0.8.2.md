# v0.8.2: the foil sheen turns back

A patch version, opened and closed on 2026-10-31, with one change. The next version is v0.8.3 ([the plan](../plans/0.8.3.md), carried from v0.8.0's close).

## Scope agreed for this version

The owner, 2026-10-31, in the chat that closed v0.8.1 (whose close had said v0.8.2 would begin in a new one): "Lets do v0.8.2 here. The foil cards have a reflective motion overlay on them, and when the shiny frames end, it chops back to the beginning and it looks awkward. Make it so that the shiny overlay plays to the end, then reverses back to the beginning, then plays forward again, and repeat indefinitely.... instead of looping. When you're finished with that change, commit and push v0.8.2. That will be the only change for that version."

## Changed

- **The foil sheen goes across and back.** The moving reflection on a foil card's picture played across the card and jumped back to its start. It now crosses, turns, crosses back and turns again, for as long as the card is on screen (`animation-direction: alternate`), easing at each turn. That is the sheen in the pack opening at Leng's counter (`shop.module.css`, `.shimmer`, 2.6 s each way) and on the auction house's item cards (`auctions.module.css`, `.foil`, 3.4 s each way). The foils' glow already breathed in and out; it is unchanged. With Reduce motion, nothing moves, as before.
- `docs/plans/0.8.2.md` is now `docs/plans/0.8.3.md`.

## Deploying 0.8.2

No migration and no `.env` change. The private images must exist at the tag first (the private repository's engine and web workflows, run once the tag's run has published the public `0.8.2` images). Then, on the VM: `cd ~/commander-duels && git pull && bash deploy/upgrade.sh`.
