# v0.8.4: the first-time tutorial

A patch version, opened and closed on 2026-11-01. The next version was v0.8.5 ([release notes](0.8.5.md)), v0.8.6 ([release notes](0.8.6.md)), then v0.8.7 ([the plan](../plans/0.8.7.md), carried from v0.8.0's close).

## Scope agreed for this version

The owner's three items, noted at v0.8.3's close ([the plan as it stood](../plans/0.8.7.md)): new welcome screenshots with the real card back, no other game named anywhere, and a first-time tutorial in three paths. At the start, the owner chose from the plan's questions:

- **The Beginner's watched game** is a scripted demo: a written game played back on the real table, not a live engine game nor a recorded one, so it shows every lesson reliably and uses no engine slot.
- **The history in the docs is reworded too**, not kept as written: the repository is public.
- **The tutorial can be opened again from Settings.**
- **Only the three items**; the carried-over notes and the bug hunt's lesser findings stay for later.

The plan's other start questions took its recommended defaults: the tutorial's path, stage and a skip are kept on the account; the 1,000 welcome tokens pay for the tour's pack, with nothing granted; the auction step lists a card from the pack just opened, with its prices suggested and nothing listed until the player confirms.

## Added

- **A first-time tutorial in three paths** ([the tutorial](../menus.md#the-tutorial-v084)). The setup wizard's welcome now asks "How would you like to start?":
  - **Beginner** watches a whole Commander game between two bots on the real table, full screen, with each move explained in a panel over it: the steps of a turn, lands and mana, casting and summoning sickness, haste, attacking, blocking and damage, mana kept back, the stack and a response, the commander, the command zone, the commander tax and commander damage, until 21 of it ends the game. Next, Back, Play on its own and Skip the game; eighteen lessons. Then the setup with a tip at each step, then the main menu's tour.
  - **Novice** reads an overview of Commander Duels (the table, the library and decks, tokens and Leng's Card Shop, Tivit's Auction House, the Alliance and the Campaign) and a refresher on Magic's rules, a page at a time. Then the setup with tips, then the tour, which a Novice may skip.
  - **Advanced** goes straight to the setup, as the wizard was before.
- **The main menu's tour** (Beginner and Novice): a bubble with an arrow and a glowing ring on what to press next. From the main menu to Leng's Card Shop ("You have some tokens! Let's go check out Leng's Card Shop and tear some packs!"), a pack bought and opened, then to Tivit's Auction House, where Sell a card opens with the pack's best card chosen and a numbered tip at each part: the card, the suggested prices (by rarity, twice for a foil, Buy Now three times the start) and List it, the only thing that lists it. Skip the tour ends it from any bubble.
- **The tutorial on the account.** `PUT /api/v1/me/tutorial` moves it along, `me.tutorial` says where it is (path, stage, skipped), and migration 0033 adds its three columns: accounts set up before v0.8.4 start at the end, those still setting up at the choice. A reload or another device picks up where the player was. SysOp's reset starts it again ([resetting an account](../identity.md#resetting-an-account-v045)).
- **Settings › Tutorial**: the guided game again, the overview in a pop-up, and the tour again, for any account.

## Changed

- **No other game named.** The name of the game the table was first modelled on is gone from everything players read (the wizard's caption for the table, the public About page and its description), from the API's published descriptions (an achievement's `addition` field, so the OpenAPI document and the web's generated types), from code comments, and from every doc, the plans and release notes of v0.0.4 to v0.5.0 and the v0.3.0 design included. Where a reference is still needed, they say "the reference game"; elsewhere the look is described in the game's own words (a 16:9 table, a title screen, packs opened card by card). The owner's private report and its other notes are untouched.
- **New welcome screenshots.** The wizard's four pictures (`web/public/welcome/{table,decks,shop,alliance}-{640,1280}.webp`) are taken again from the current game: the table is the guided game's board, with both libraries and the opponent's hand showing the real card back, and the pack at Leng's counter is half turned over, the rest face down with the real card back. They are taken by `web/e2e/welcome-shots.spec.ts` on demand (`CD_E2E_WELCOME_SHOTS=1`) and made into the two sizes by `scripts/welcome_shots.py`. Their alternative text says what they now show.
- **The game screen draws a scripted game** (`GameScreen`'s `scripted` state): no connection, no summary, no lock on leaving, nothing to answer. Only the tutorial uses it.

## Deploying 0.8.4

Migration 0033 adds three columns to `users`, with defaults, so v0.8.3 keeps serving while it runs; no `.env` change. The private images must exist at the tag first (the private repository's engine and web workflows, run once the tag's run has published the public `0.8.4` images). Then, on the VM, as always: `cd ~/commander-duels && git pull && bash deploy/upgrade.sh`.
