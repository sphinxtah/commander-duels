# Plan for v0.4.1: fixes for what the owner finds

Prepared on 2026-10-21, when v0.4.0 closed. The owner named the next version v0.4.1: a patch for the minor issues and bugs the owner finds, playing the live site after v0.4.0's deploy. The owner's own list leads; this plan only gathers what v0.4.0 left open, so the first chat of v0.4.1 can start from it. It proposes; the owner decides at the start.

## Where v0.4.0 left things

- **Tokens** for every win, the welcome grant and back pay, SysOp's grants and the bots' daily cap ([tokens](../tokens.md)).
- **Human tables:** a lobby, invite links, bots in the empty seats, a vote to remove an absent player ([human tables](../tables.md)).
- **Leng's card shop:** 392 booster products priced from market prices, collations from MTGJSON, opening in the Magic Duels style ([the shop](../shop.md)).
- **The Godlike tier's custom cards in play,** from the owner's private engine image ([progression](../progression.md)).
- **Long choices at the table:** a creature type listed with a filter, a card's name typed ([prompts](../engine/commander-tables.md#prompts)).
- **Evidence:** CI run #71 and the local checks ([release notes](../releases/0.4.0.md#verification)).

## Start with

1. **The owner's list.** Each issue the owner reports, reproduced first (a test or a journey that fails), then fixed. Anything that turns out to be a new feature rather than a defect is noted for a minor version instead.
2. **What v0.4.0 could not check by hand,** on the live site after its deploy:
   - the private engine image on the VM, and the custom cards in a real game, seen from both sides of the table;
   - a human table between two real players, including an away vote;
   - the shop's first booster data run against the live catalog, and a pack bought and opened;
   - a real win's tokens, and the back pay of past wins in each player's ledger.
3. **Choices the v0.4.0 build made without asking,** for the owner to keep or change:
   - a table's game waits up to an hour without an answer before the engine ends it (practice games keep 15 minutes);
   - the host leaving closes the table, and a table nobody starts closes after 3 hours;
   - no pack costs less than 10 tokens, and a set MTGJSON adds after the price list sells at 500 until priced;
   - the booster data job runs weekly;
   - the private set's name, "Commander Duels: The Sphinx" (the cards print only its code).
4. **Housekeeping.** Old git worktrees from earlier versions under `.claude/worktrees/` make every `git gc` report "Permission denied"; remove them once nothing needs them.
